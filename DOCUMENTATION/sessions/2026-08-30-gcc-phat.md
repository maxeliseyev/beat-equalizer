# 2026-08-30 — GCC-PHAT

## Context

PR 1 влит. Следующий шаг плана — оценка TDOA без UI.

## What

- `src/dsp/Fft.cpp` — radix-2, без JUCE (тесты не поднимают GUI, нет двойной
  линковки `juce_dsp` в plugin + dsp-lib).
- `src/dsp/GccPhat.cpp` — PHAT, полоса 100–8000 Hz, поиск только в `[-τmax,+τmax]`,
  парабола, полярность по сумме `ref[i]*sig[i+lag]`.
- Положительный лаг = `signal` позже `reference` (`Y * conj(X)`). Первый прогон
  тестов показал обратный знак — перевернули спектры, не тесты.
- `tests/test_gcc_phat.cpp`. Плагин не подключён.

## Why

`juce::dsp::FFT` в `beat_dsp` заставил бы компилировать модуль и в либе, и в
плагине. Для офлайн-анализа свой FFT достаточный; pffft — если worker не будет
успевать.

Полярность не из знака PHAT-пика: PHAT выкидывает магнитуду.
