# 2026-08-30 — AGENTS.md и правила репо

## What

Добавлены корневой `AGENTS.md`, `.clang-format`, индекс `DOCUMENTATION/`,
папки `sessions/` и `decisions/`, первый ADR про топологию MVP.
README указывает на план и контракт, а не на ярлык `mvp-juce-plan.md`.

## Why

Агенту нужен короткий список того, что нельзя «улучшить»: realtime, PDC,
окно GCC, полярность не из PHAT, стабильные parameter ID, запрет ARA и FFTW.
Полные планы уже есть — дублировать их в AGENTS.md нельзя, иначе разъедутся.

Альтернатива — размазать правила по `.grok/rules/*.md`. Для репо этого размера
один корневой файл проще сопровождать; поддиректории можно добавить, когда
DSP и plugin начнут жить разными темпами.

## Follow-ups

- Когда появится GCC-PHAT — ADR на полосу 100 Hz…8 kHz и τmax, если пороги
  зафиксируются тестами, а не останутся черновыми.
- `clang-format` на уже написанный скелет не гонялся в этом изменении.
