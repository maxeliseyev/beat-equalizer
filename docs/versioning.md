# Версии

Semver: `major.minor.patch`. Один файл — `VERSION` в корне. CMake и JUCE
читают его, плагин показывает в заголовке. Не дублировать номер в трёх местах.

## Что бампать

Пока `0.x` (до первой изданной версии):

| Бамп | Когда |
|---|---|
| **patch** (`0.1.1`) | Документация, сборка, баг без нового поведения для пользователя |
| **minor** (`0.2.0`) | Новое поведение: delay, scope, Analyze, новый алгоритм |
| **major** (`1.0.0`) | Первая версия, которую отдают наружу / продают. Дальше — `develop` |

После `1.0.0`: major = ломающий контракт (формат состояния, шины), minor =
фича, patch = фикс.

## Как

В том же PR, что и изменение:

1. Правка `VERSION`.
2. Запись в `CHANGELOG.md` сверху.
3. Не ставить git-тег с feature-ветки. Тег `vX.Y.Z` — на `main` после merge,
   когда артефакт реально отдают (тестеру, в DAW). Не каждый merge.

`make version` печатает текущий номер.
