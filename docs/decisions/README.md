# Decisions

Короткие ADR. Имя: `kebab-case.md`.

Писать, когда один и тот же вопрос всплывёт снова (шина vs отдельные bus,
PHAT vs обычная корреляция для полярности, JUCE tag, ARA). Не писать на
очевидный багфикс.

Секции: Context, Decision, Alternatives, Consequences.
Сверху: **Status** (`accepted` / `superseded` / `deferred`) и дата.

Superseded ADR не удалять — в шапке ссылка на тот, что заменил.
