# Analyze берёт файлы, если они загружены, а не вход устройства

Status: accepted  
Date: 2026-08-31

## Context

В Standalone число каналов плагина задаёт аудиоустройство. Обычная звуковая
карта отдаёт два входа, а на стенде лежит кит из восьми-шестнадцати дорожек.
Кольцевой буфер живого входа физически не увидит больше, чем даёт устройство.

## Decision

Если в стенде загружены файлы, Analyze читает окно **из них**, а не из кольца.
Живой вход остаётся источником только тогда, когда файлов нет — то есть в
плагине внутри хоста и в Standalone без загруженного материала.

Проигрывание при этом ограничено каналами устройства: слышно первые 1-2, а
анализ и экспорт видят весь кит. Экспорт вообще офлайн и от устройства не
зависит.

## Alternatives

- Заставить Standalone открыть N каналов: JUCE берёт разводку у устройства,
  без агрегированного устройства это не обойти, а собирать его ради стенда —
  требование к пользователю, а не к плагину.
- Анализировать только живой вход: тогда стенд не решает свою единственную
  задачу — прогнать реальный кит без DAW.

## Consequences

Пока файлы загружены, кнопка Analyze не смотрит на живой вход, даже если он
идёт. Очистка стенда (`FilePlayer::clear`) возвращает поведение к кольцу.
Проверка на реальном ките (plan.md, PR 8) идёт через стенд, а не через
многоканальное устройство.
