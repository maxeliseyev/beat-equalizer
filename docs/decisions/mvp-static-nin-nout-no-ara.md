# MVP: static N-in/N-out, no ARA

Status: accepted  
Date: 2026-08-30

## Context

Полный продукт (`drum-editor-plan.md`) требует ARA 2: общий документ между
инстансами, доступ к файлу целиком, по-ударная нарезка. Для первого слышимого
результата ARA — лишняя лицензия Celemony и другой хостовый контракт.

## Decision

Этап 1 — обычный VST3/AU/Standalone:

- один инстанс, один input bus и один output bus, 2…24 канала, `in == out`;
- все стемы маршрутизируются в этот инстанс (Reaper: многоканальная дорожка);
- анализ по кольцевому буферу + Analyze, не по файлу;
- одна задержка и полярность на канал, не по ударам.

## Alternatives

- Именованные моно-шины на каждый микрофон — плохо живут в AU, усложняют первый хост.
- Инстанс на дорожку + sidechain — не видит полный кит без ARA.
- Сразу ARA — откладывает проверку DSP на месяцы.

## Consequences

Ableton как хост MVP не рассматриваем. Logic не блокер. Windows — после macOS.
Этап 2 имеет право заменить топологию; этап 1 не должен её предвосхищать в коде.
