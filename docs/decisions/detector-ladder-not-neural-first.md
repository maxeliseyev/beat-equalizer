# Детектор: лестница, сеть не первая

Status: accepted  
Date: 2026-08-30

## Context

В `drum-editor-plan.md` §3.3 фигурировали RTNeural/ONNX как «второй этап».
Нужно зафиксировать порядок, иначе Analyze начнётся с рантайма вывода.

## Decision

Канон — `docs/detector-design-recommendations.md`.

- Детектор сменный (`IOnsetDetector` → `Event`); стек выше не знает реализацию.
- Ступени 1–4 без обучения. Сеть — с 5, сначала классификация уже найденного.
- Субсэмплевое время всегда GCC-PHAT, сеть его не заменяет.
- ONNX/RTNeural не добавлять в зависимости, пока нет модели и замороженного теста.

## Alternatives

Начать с общей многоканальной модели — дорого, другая задача, нет датасета.
Правки пользователя без разделения «ошибка / не трогать» делают датасет мусором.

## Consequences

Первый онсет-детектор — spectral flux + голосование + физические лаги.
Интерфейс сразу несёт confidence, origin, признаки.
