# 2026-08-31 — Осциллограмма в строке канала, строки по материалу стенда

## Context

Вопрос из работы со стендом: как вообще грузить кит из отдельных WAV и почему,
загрузив шестнадцать дорожек, в UI видно две строки. Ответ был в раскладке:
число строк бралось у звуковой карты, а осциллограф жил отдельной панелью под
таблицей, где трассы стояли не напротив своих ручек.

Не шаг `plan.md` — правка UI между PR 7 и PR 8, чтобы прогон на реальном ките
вообще можно было смотреть глазами.

## What

- `ChannelRow` владеет своим `ScopeStrip`: строка = ручки слева, трасса справа.
  `ChannelColumns` получил колонку `scope`, ширины ручек стали фиксированными.
- `ScopeStrip::setShowIndex(false)` — номер канала уже стоит в колонке Ch.
- Редактор: панель осциллографа и её viewport убраны, шкала времени переехала
  в шапку над колонкой трасс, высота окна = `chromeHeight() + N * kHeight`.
- `activeChannelCount()` = `max(входы устройства, каналы стенда)`.
- `FilePlayer::readDisplayWindow()` — окно канала для отрисовки из клипа.
- Тесты: колонки с трассой, отрисовка трассы внутри строки, линейный рост окна,
  строки по загруженным файлам (`per-channel-scopes-test.png`), совпадение
  пиков в окне отрисовки при сдвиге на задержку.

## Why

**Трасса в строке, а не отдельной панелью.** Выравнивание смотрят парами
«ручка — трасса»: при двух панелях глаз держит соответствие сам, и на восьми
каналах он ошибается. Плата — высота окна; она принята сознательно, окно растёт
вниз линейно, вширь не растёт совсем.

**Ширины колонок зафиксированы.** Раньше Delay забирал весь остаток; теперь
остаток нужен трассе, а слайдер на 1600 px шириной всё равно не точнее.

**Прокрутки нет по умолчанию.** Окно само встаёт под число каналов, viewport
таблицы остался только страховкой на случай, когда высоту сжали руками.

**Осциллограммы стенда берутся из файлов, а не из кольца выхода.** Кольцо
пишется в `processBlock` и физически видит только каналы устройства — на
двухвходовой карте трассы 3…16 были бы пустые. Сдвиг, полярность и A/B в окне
считаются из тех же параметров, что и в аудиопотоке, поэтому картинка
показывает то, что уйдёт в `Export aligned`. Ротатор в отрисовке не применяется:
на огибающей его почти не видно, а честная реализация означала бы фильтр по
всем каналам 25 раз в секунду в message thread. Расширение ADR
`decisions/standalone-analyzes-files-not-the-device.md`.

**На паузе окно стоит на первом ударе.** Позиция стенда = 0, и окно «последние
N отсчётов до позиции» показало бы хвост тишины перед нулём — сразу после Load
строки выглядели бы пустыми.
