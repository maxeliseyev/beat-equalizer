# 2026-08-31 — Standalone-стенд, экспорт и персистентность (PR 7)

## Context

По `plan.md` PR 7 — Standalone loader, export aligned WAV и состояние, которое
переживает открытие проекта. Это то, ради чего стенд задумывался: прогнать
реальный кит без сборки шестнадцати шин в DAW.

## What

- `src/dsp/AnalysisState.{h,cpp}` — версионный блоб оценок, без JUCE.
- `FractionalDelay::snapToTargets()` и `AllpassRotator::snapToTargets()`.
- `src/plugin/FilePlayer.{h,cpp}` — загрузка нескольких файлов подряд по
  каналам, приведение к частоте устройства, транспорт по кругу, окно для Analyze.
- `src/plugin/Exporter.{h,cpp}` — офлайн-рендер той же цепочки и запись WAV.
- `PluginProcessor`: файлы подменяют вход, `readWindow` для worker-а,
  `exportAligned()`, блоб в `getStateInformation` / `setStateInformation`.
- Редактор: ряд стенда Load / Play / Export, виден только в Standalone.
- Тесты: `test_analysis_state`, `test_standalone` (рендер, транспорт, окно
  анализа, экспорт с чтением обратно, восстановление состояния).

## Why

**Analyze берёт файлы, а не вход устройства** — ADR
`decisions/standalone-analyzes-files-not-the-device.md`.

**Материал приводится к частоте устройства при загрузке.** Иначе 44.1 kHz файл
на 48 kHz устройстве дал бы одну задержку в сэмплах для анализа и другую для
экспорта. Один тайминг на всё — `LagrangeInterpolator` при загрузке.

**`snapToTargets()` вместо сглаживания в экспорте.** Realtime-цепочка выезжает
на ручках за 5 мс, и без этого первые миллисекунды экспорта были бы выровнены
неправильно. Тест на импульсах ловит это: пики двух каналов обязаны совпасть.

**Экспорт длиннее исходника** на `ceil(max delay) + latency интерполятора` —
хвост самого задержанного канала не срезается. Общий сдвиг кита на max(TDOA)
не компенсируется: внутри файла каналы выровнены, а это и есть цель стенда.

**Блоб хранит оценки, а не задержки.** Задержки, полярность и ротатор уже живут
в APVTS и восстанавливаются хостом; блоб нужен, чтобы после открытия проекта
были видны уверенность и когерентность. Версия и число каналов проверяются:
чужой блоб не читается вовсе.

**`SpinLock::ScopedTryLockType` в `fill()`.** Аудиопоток не ждёт загрузку: если
буфер меняют, блок просто не подменяется.
