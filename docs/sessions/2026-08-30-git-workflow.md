# 2026-08-30 — git-флоу без develop до v1

## What

Зафиксирован trunk-based поток: `main` + обязательные PR, squash.
`develop` откладывается до первой изданной версии. Описание в
`docs/git-workflow.md`, инвариант в `AGENTS.md`, ADR
`decisions/git-trunk-until-v1.md`.

## Why

Два разработчика и нет продакшена. `develop` сейчас — второй `main` без
пользователей на первом: путаница целевой ветки у людей и агентов, церемония
релиза без релиза.

Альтернатива «завести develop сразу, как в Git Flow» отвергнута: смысл
`main` как неприкасаемой линии появляется только когда линию уже нельзя
ломать следующим этапом (ARA). До этого PR в `main` и есть интеграция.

Прямой пуш отвергнут: второму разработчику и ревью негде включиться.

## Follow-ups

- В GitHub на `main`: Require a pull request before merging.
- Когда появится CI — включить required status check.
- При теге `v1.0.0` обновить AGENTS и git-workflow одним PR, завести `develop`.
