# 2026-09-03 — Basic/Advanced UI rollout

## Context

PR #39 смёржен: source-centric diagnostics видны в Standalone, но экран стал
ещё ближе к инженерному стенду. Пользователь зафиксировал продуктовый риск:
новый плагин не должен сразу показывать весь набор ручек и диагностик.

## What

План Basic/Advanced разложен на серию PR:

1. каркас режима, `global.uiMode`, header toggle и видимость top-level блоков;
2. mode-aware таблица каналов;
3. Basic outcome/status вместо инженерных строк;
4. Advanced diagnostics v2 с полной source-centric таблицей и ролями каналов.

Текущая ветка начинает первый пункт. DSP, matcher, glide и export в этом PR не
меняются.

Первый пункт реализован:

- добавлен `global.uiMode` (`Basic`, `Advanced`), default `Basic`;
- в header добавлен переключатель Basic/Advanced;
- Basic скрывает top-level advanced-блоки: max distance/freeze, glide strength,
  source status, correlometer, grid/time/tempo controls;
- Advanced возвращает текущий инженерный экран;
- высота editor-а и resize limits пересчитываются при смене режима;
- добавлен GUI-тест на default Basic, раскрытие Advanced и пересчёт высоты.

## Why

Самый рискованный путь — одновременно менять алгоритмы, таблицу каналов,
тексты статусов и компоновку. Тогда любой регресс в маркерах, задержках или
экспорте будет трудно локализовать. Поэтому первый PR делает только
персистентный режим и слой видимости: это даёт основание для следующих UI PR,
но не меняет смысл измерений.

`global.uiMode` выбран вместо локального поля editor-а, потому что режим
интерфейса — пользовательское состояние проекта/плагина. Это новый стабильный
параметр, но он не переименовывает и не переупорядочивает существующие channel
parameters; параметр добавлен после существующих параметров, чтобы не двигать
их порядок.
