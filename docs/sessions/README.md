# Session notes

Имя: `YYYY-MM-DD-<topic>.md`. Без YAML-frontmatter.
Шаблон и правила смены: `../handoff.md`.

Минимум секций: **Context**, **What**, **Why** (обязательно), **Status**, **Next**, **Open**.

Не заменяют `status.md`. Курсор «где мы» туда не копировать целиком —
в Status достаточно «status.md обновлён: да. Ветка: …».

Если вывод ограничит будущее — ещё `../decisions/<slug>.md` в том же изменении.
